# RangpurEvent

A community website for create, join, and manage events in Rangpur.

Live Site: https://rangpur-event-frontend.vercel.app

## Features
- Users can register and login with email/password or Google using BetterAuth.
- Logged-in users can create new upcoming social events
- Anyone can browse upcoming events.
- Logged-in users can join events, see all their joined events.
- Event creators can edit or delete their own events
- Includes light/dark theme toggle and a profile update page.

## Tech Used
- Next.js, TypeScript, Tailwind CSS, Shadcn UI, React Hot Toast
- BetterAuth, JWT
- Express.js, MongoDB
